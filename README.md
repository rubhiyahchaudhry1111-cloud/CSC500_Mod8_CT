# Online Shopping Cart (Python)

## 📌 Project Overview
This project is a menu-driven **Online Shopping Cart** program written in Python.  
It was developed as a **Portfolio Project** and follows all required milestones, including object-oriented design, user input handling, and cart manipulation features.

The program allows a user to:
- Enter customer information
- Add items to a shopping cart
- Remove items from the cart
- Change item quantities
- View item descriptions
- View the total shopping cart cost

---

## 🧱 Program Structure

### Classes
- **ItemToPurchase**
  - Stores item name, description, price, and quantity
  - Prints item cost in the required format

- **ShoppingCart**
  - Stores customer name, date, and list of items
  - Supports adding, removing, modifying items
  - Calculates total items and total cost
  - Prints cart contents and item descriptions

### Main Features
- Menu-driven interface
- Input validation for menu options
- Outputs formatted exactly as required by the assignment
